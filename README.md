# Xinye Xie — personal website

English academic website built with the official al-folio v1 starter and
versioned al-folio runtime gems. Name: Xinye Xie (谢鑫晔).

Navigation: **Home · Research · CV · Blog**.

| Content | File |
| --- | --- |
| Home | _pages/about.md |
| Research (the Publications page) | _pages/publications.md |
| Publications | _bibliography/papers.bib |
| CV | _pages/cv.md |
| Blog | _pages/blog.md and _posts/ |
| Identity and theme settings | _config.yml |
| Contact links | _data/socials.yml |

No sample publications, fabricated biography, demo posts, or placeholder PDF links
are published. Unknown information is explicitly marked as coming soon.

See [DEPLOYMENT.md](DEPLOYMENT.md) to publish on GitHub Pages and
[CONTENT-CHECKLIST.md](CONTENT-CHECKLIST.md) to fill in your materials.

## Local preview

With Ruby 3.3.5 and Bundler installed, run:

    bundle install
    bundle exec jekyll serve

Visit http://localhost:4000/. The workflow builds and checks all four pages
before deploying. Use this directory as the repository root.
